# Contributing

Ideas and fixes are welcome.

- **Suggest a feature or report a bug:** open an issue.
- **Change the code:** fork the repository and open a pull request. Only the maintainer merges changes into `main`.
- **License of contributions:** by sending code you agree it is released under the project's license, GPL-3.0-or-later, and that you have the right to share it. Do not add code or files you do not have permission to use.
- Keep changes small and focused, and make sure the build passes.
